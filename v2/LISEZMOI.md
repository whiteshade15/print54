# Print54 V2 — site web

Site statique : `index.html`, `assets/style.css`, `assets/app.js`, `img/`. Aucun serveur ni base de données.
Langues : FR (dans le HTML), NL et EN (dans `assets/app.js`). La langue suit le navigateur du visiteur, puis son choix est mémorisé.

## Mise en ligne sur print54.be (One.com)
1. Retirer la ligne `<meta name="robots" content="noindex, nofollow">` dans `index.html`.
2. Copier tout le dossier à la racine de l'hébergement (Gestionnaire de fichiers ou FTP).
